# Lbrty

Portfolio website with five server-protected case studies, built for Cloudflare Workers Free. Domain registration can remain at MijnDomein.

See [hosting and launch instructions](docs/hosting.md). Run `pnpm install --frozen-lockfile`, `pnpm test`, then `pnpm run dev` with the required secrets in an ignored `.dev.vars` file. The static source files are not a secure deployment by themselves.
